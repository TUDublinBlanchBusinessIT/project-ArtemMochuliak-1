# Swapify – Mobile App Project

Swapify is a sustainable, community-driven mobile application designed to help users exchange items locally instead of buying new ones. The app enables users to post items, browse listings, chat with others, and complete eco-friendly swaps — promoting waste reduction and stronger community connections.

## What Swapify Does:

-Swapify provides a simple platform where users can:

-Post items they want to swap with photos and details

-Browse items posted by others in their local area

-Search and filter by category, condition, and location

-View detailed item information with images

-Send and receive messages to coordinate swaps

-Manage their own profile and view their posted items
